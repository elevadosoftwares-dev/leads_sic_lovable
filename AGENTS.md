- Stack: TanStack Start (React + Node server functions) with SQL Server via `mssql`. Server-only code lives in `src/server/*.server.ts` and is loaded with `await import(...)` inside server functions; schema changes go in `database/schema.sql` and must stay idempotent.
- Signed-in pages live under src/routes/_authenticated/ (client-only gate). Roles are `admin` / `viewer` in `dbo.users.role`: every signed-in user can read, only admins write. Guard server functions with `requireAuth` (reads) or `requireAdmin` (writes) from src/lib/auth-middleware.ts, and gate mutating UI with useIsAdmin() from src/lib/data.ts.
- Uploaded files go in `dbo.files` (via `uploadFile` in src/lib/data.ts) and are shown through `/api/files/:id`, which only serves signed-in users. Rows store the file id (`image_id` / `attachment_id`); a new table that references files must also be added to the cleanup query in src/lib/files.functions.ts.
